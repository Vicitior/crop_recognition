## 🚀 微信云托管 3 步一键部署步骤

### 第一步：在微信开发者工具中开通云托管

1. 打开 **微信开发者工具**，加载小程序工程 `wechat_mini_program/`。
2. 在开发者工具顶部菜单栏，点击 **“微信云托管”** 按钮。
3. 首次使用点击 **“免费开通”**（新用户享免费额度试用），创建一个云托管环境（例如环境名称填：`prod-crop-recognition`）。

---

### 第二步：一键构建并发布后端服务

1. 进入微信云托管控制台，点击 **“服务列表” -> “新建服务”**。
2. 服务名称填入：`crop-api`。
3. 选择 **“代码发布” -> “本地代码上传”** 或 **“绑定 GitHub 仓库”**（选择本项目仓库 `crop_recognition`）。
4. 点击 **“发布版本”**，云托管会自动读取项目根目录的 `Dockerfile` 完成一键镜像构建与上线部署！

---

### 第三步：小程序一键绑定

1. 构建完成后，云托管控制台会生成一个 **环境 ID**（例如 `prod-1gxxx`）。
2. 在小程序首页点击右上角的 **`⚙️ 服务器`** 按钮：
   - 通信模式选择：**`☁️ 微信云托管 (免 IP/公网域名)`**
   - 填入你的**环境 ID**，点击 **保存设置**。
3. 大功告成！之后全世界任何人在手机微信里扫码打开小程序，都可以直接进行农作物 AI 识别，不需要你的电脑开机！
